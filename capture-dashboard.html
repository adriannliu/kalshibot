There is no trading kill switch, and that is deliberate

This system is read-only. It has no execution engine, no order state machine, and no position — so there is nothing to halt and no capital to protect. The safeguard is structural: tests/test_layering.py fails the build if any module in the trading path gains an order-submission call site. The kill switches in §7 of the north star — stale feed, position mismatch, inventory breach, daily P&L floor, sustained 429s — get built in Phase 5, against a demo account, behind chaos testing. Building them now would imply the system is safe to trade before Phase 2 has said whether an edge exists at all.
